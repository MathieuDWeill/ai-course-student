# Data Science -> ML Engineering -> Applied AI

Objectif: former des etudiants capables de passer d'une analyse de donnees a un systeme IA utilisable, documente et publiable.

## Module 1 - Python for Data Science (S4)

Objectifs:
- manipuler et transformer des donnees avec Python;
- produire une analyse exploratoire claire;
- construire et evaluer des premiers modeles ML;
- communiquer resultats, limites et decisions.

Sessions:
1. Introduction data science, notebooks, signaux faibles
2. Pandas: nettoyage, types, valeurs manquantes
3. EDA, visualisation, storytelling
4. ML supervise: baseline et evaluation
5. ML non supervise: clustering et reduction de dimension
6. Pipeline reproductible
7. Projet encadre
8. Restitution

Livrables:
- notebooks propres;
- dataset documente;
- analyse decisionnelle courte.

## Module 2 - Advanced ML + MLOps (S3)

Objectifs:
- entrainer et evaluer des modeles ML avances;
- comprendre reseaux de neurones, optimisation et regularisation;
- deployer un modele et documenter le cycle MLOps;
- produire une demo technique exploitable.

Sessions:
1. Rappels ML et modeles avances
2. Reseaux de neurones et architectures de base
3. Optimisation et regularisation
4. Evaluation, erreurs et generalisation
5. Packaging et experiment tracking
6. API ou demo de prediction
7. Documentation technique
8. Soutenance projet

Livrables:
- projet ML deploye;
- documentation technique;
- rapport et soutenance.

## Module 3 - NLP + Computer Vision (S4)

Objectifs:
- utiliser des modeles NLP modernes et pre-entraines;
- construire une application texte, image ou multimodale;
- evaluer performance, usage et limites;
- integrer une analyse ethique.

Sessions:
1. Introduction NLP et methodes classiques
2. Embeddings et transformers
3. BERT/GPT pour cas applicatifs
4. Introduction computer vision et CNN
5. Modeles pre-entraines vision
6. Application NLP/Vision
7. Evaluation et ethique
8. Soutenance projet

Livrables:
- application IA complete;
- rapport incluant limites et ethique;
- asset portfolio public.

## Projet transversal

Fil rouge: weak signal -> dataset -> insight -> model -> deployment -> intelligent application.

Chaque module ajoute une couche de maturite: analyse fiable, systeme ML, puis application IA.
