# Comment suivre le parcours

Conception pédagogique : Mathieu Weill.

Chaque séance suit une fiche de démarrage commune. Les supports étudiant comprennent le cours, les exemples expliqués, les consignes et les exercices. Les notes d’animation, réponses aux exercices, barèmes et corrigés restent dans l’espace professeur. Une démonstration résolue est un exemple de cours ; elle ne constitue pas le corrigé d’un exercice à rendre.

## Pendant la séance

Le professeur annonce les objectifs et les prérequis, montre un premier raisonnement puis organise des points d’arrêt. Avant un calcul, chacun écrit une prévision ; après, une observation et une conclusion. Les manipulations sont accompagnées de vérifications collectives. Les modalités et horaires précis sont annoncés en séance.

## Pour travailler seul entre deux séances

Ouvrir la fiche, retrouver la dernière étape comprise et refaire son contrôle. Conserver une question précise si le blocage persiste. L’extension commence après le socle, pas à sa place. Un assistant de code peut aider ; chaque étudiant doit pouvoir expliquer une modification et son effet.

## Supports et livrables

Le notebook sert à manipuler. Le PowerPoint conduit les explications. Le PDF rédigé sert à reprendre et réviser le raisonnement ; un export de slides est identifié comme tel. Le catalogue indique explicitement ce qui est déjà publié et ce qui manque encore. Aucune note ni échéance nouvelle n’est fixée par cette documentation.

Les consignes d’évaluation distinguent exercices d’apprentissage, exemples résolus et travaux à rendre. Les résultats et traces individuelles rendent visible la progression ; ils servent aussi à repérer les notions à reprendre.
