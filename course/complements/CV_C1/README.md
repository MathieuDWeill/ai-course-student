Conception pédagogique : Mathieu Weill.

Après **CV_01** ; durée indicative **60 min**.

[PDF](cours.pdf) · [PowerPoint](presentation.pptx) · [Notebook](notebook.ipynb)

## Objectif

Distinguer les sorties et calculer une IoU, puis lire des inférences préentraînées sans les présenter comme des annotations.

## Déroulé accompagné

Lire les quatre notions avec le professeur. Pour D1 puis D2 : prévoir une sortie, exécuter et expliquer une assertion. Répondre individuellement à l’exercice puis corriger collectivement. Le professeur accompagne les commandes supplémentaires de l’application.

## Préparation

Conserver le dossier parent avec `laboratoire`. Utiliser les [consignes d’installation](../README.md). Les démonstrations CNN demandent PyTorch ; les modèles préentraînés sont téléchargés uniquement avec l’option explicite indiquée. Une panne de téléchargement limite l’activité : ne pas déclarer une inférence qui n’a pas été faite.
