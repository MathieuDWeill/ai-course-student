# Correspondance syllabus et supports disponibles

Le parcours couvre Python pour la Data Science, ML avancé/MLOps et NLP/vision. La présence de supports ne certifie pas que chaque activité a déjà été réalisée ou acquise.

- Python : PY_01 à PY_07 et ateliers historiques ; PY_C1 complète la hiérarchie et l’analyse des conséquences d’usage.
- ML avancé : AML_01 à AML_06 ; AML_C1 relie CNN et optimisation, AML_C2 ajoute API REST, CI, supervision et procédure de retour.
- NLP : NLP_01/NLP_02 ; NLP_C1 ajoute génération GPT-2 distillée, résumé et assistant documentaire.
- Vision : CV_01/CV_02 ; CV_C1 ajoute boîtes, masques, détection et segmentation ; MM_C1 assemble texte et image avec ablations et analyse éthique.

Les démonstrations de service sont locales. Le suivi dans le temps, la mise en production distante et les projets finaux demandent une réalisation distincte ; ils ne sont pas déduits d’un score Kaggle. Les volumes et modalités d’évaluation relèvent du planning et des consignes institutionnelles.
