# Kaggle Strategy - Code + Datasets First

Objectif: atteindre Kaggle Expert rapidement par publications regulieres, utiles et reproductibles.

## 5 notebook ideas

1. Google Trends Weak Signals: detect early attention shifts with public snapshots.
2. From Dirty CSV to Decision: compact pandas cleaning case study.
3. EDA Storytelling Template: one dataset, one question, one decision.
4. Baseline First ML: simple model, honest validation, clear error analysis.
5. Dataset Quality Report: missingness, duplicates, drift and documentation.

## 3 dataset ideas

1. Google Trends public snapshots for tech/product keywords.
2. Cleaned open city mobility or weather indicators with data dictionary.
3. Small business KPI sample dataset for BI and decision-making exercises.

## Fastest path to Expert

- Publish Code first: 1 clean notebook per week, short narrative, reproducible outputs.
- Publish Datasets second: small, documented, easy to reuse, with a starter notebook.
- Reuse a consistent notebook structure: question, data, cleaning, EDA, insight, limits.
- Optimize for usefulness, not complexity: simple datasets get reused faster.
- Comment on related notebooks and link improvements back to course assets.

Minimum cadence: 8 useful notebooks + 3 documented datasets over one teaching cycle.
