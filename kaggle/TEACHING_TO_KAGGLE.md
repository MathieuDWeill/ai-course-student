# Teaching to Kaggle Bridge

Objectif: convertir les livrables de cours en actifs publics qui accelerent la progression Kaggle Code + Datasets.

## Conversion des modules

Python for Data Science:
- publier les notebooks EDA et nettoyage;
- transformer les snapshots en petits datasets documentes;
- viser des notebooks simples, utiles, reproductibles.

Advanced ML + MLOps:
- publier des baselines propres avec evaluation honnete;
- ajouter des notebooks de comparaison de modeles;
- documenter erreurs, limites et decisions de validation.

NLP + Vision:
- publier des notebooks d'application avec modeles pre-entraines;
- privilegier datasets legers et cas d'usage clairs;
- inclure section ethique et limites.

## Assets Kaggle prioritaires

Code:
- EDA storytelling notebook;
- cleaning case study;
- baseline ML notebook;
- error analysis notebook;
- NLP/Vision starter notebook.

Datasets:
- Google Trends snapshots documentes;
- dataset nettoye + data dictionary;
- dataset pedagogique pour classification ou recommandation.

## Regle de publication

Un livrable de cours devient publiable si:
- il s'execute top-to-bottom;
- la question est claire;
- le dataset est cite et documente;
- la conclusion est utile;
- les limites sont visibles.

## Chemin Expert

1. Publier 3 notebooks Data Science courts.
2. Publier 1 dataset Google Trends documente.
3. Publier 2 notebooks ML baseline + error analysis.
4. Publier 1 dataset nettoye reutilisable.
5. Publier 2 notebooks Applied AI avec NLP/Vision.

Priorite: regularite, clarte, reutilisabilite.
