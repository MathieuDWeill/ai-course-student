# Shared Project Framework

Fil rouge: From weak signals to intelligent applications.

## Principe

Tous les projets suivent la meme logique, avec complexite croissante:

1. Weak signal: observer un phenomene public.
2. Data analysis: nettoyer, explorer, raconter.
3. Model: predire, classer, recommander ou detecter.
4. Deployment: rendre le modele utilisable.
5. Intelligent application: integrer texte, image ou multimodal.

## Niveau 1 - Google Trends / Data Science

Livrable:
- notebook EDA propre;
- dataset documente;
- decision memo court.

Question type:
- quel signal monte, baisse ou diverge?
- quelle decision peut-on raisonnablement soutenir?
- quelles limites empechent de surinterpretrer?

## Niveau 2 - ML Engineering / MLOps

Livrable:
- pipeline d'entrainement;
- baseline comparee a une version amelioree;
- API ou demo locale;
- rapport technique court.

Question type:
- le modele generalise-t-il?
- quelles erreurs sont acceptables?
- comment versionner, tester et redeployer?

## Niveau 3 - NLP / Vision / Applied AI

Livrable:
- application NLP, vision ou multimodale;
- evaluation qualitative et quantitative;
- analyse ethique;
- asset portfolio public.

Question type:
- quelle tache utilisateur est automatisee ou augmentee?
- quelles donnees rendent l'application fiable?
- quels risques doivent etre documentes?

## Definition of done

- executable de bout en bout;
- dataset ou source citee;
- limites explicites;
- resultat comprehensible par un non-specialiste;
- asset reusable sur GitHub ou Kaggle.
