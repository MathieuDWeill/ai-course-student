- `ESEO_S3_Cours_Complet_V2.pptx` : support de cours S3, version 2.
- `ESEO_S4_Question_Modele_Atelier.pptx` : atelier S4, de la question au modèle, version vérifiée (61 diapositives). Contrastes et extraits Python corrigés ; comparaison sur validation et test final réservé.

Pour S4 : les diapos 44–60 servent de fiches d'aide pendant l'atelier ;
la diapo 61 récapitule les règles. Les extraits Python sont à adapter aux données ;
les diapos 46–47 illustrent train/validation/test pour des observations indépendantes.
Pour les matchs, utiliser un découpage chronologique.
